# LibraryManagmentSystems

##Description 
Here is a basic python code based on Library Managment Systems. The user can add any book to the program, list all books, find a book by title/author and exit the program

This project used object oriented fucntions and programming

##Files

### book.py
This file has the book class

The Book class holds:
- Title 
- Author 
- ISBN
It also has the __str__ method is used to print the information about the book, and the 'get_details' method that returns the details of a book

###library_manager.py 
This file is the primary LibraryManagementSystems file.

It contains functions that will allow you to:
- Add a book
- List all books
- Find a book 

The program uses a menu to let the user select what they want to do

## How to run
1. Make sure 'book.py' and 'library_manager.py' are in the same folder
2. Open the project in VSCode
3. Run'library_manager.py'
4. Select something from the Menu

The menu options are:
1. Add a new book
2. List all books
3. Find a book
4. Exit
